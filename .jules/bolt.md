## 2024-05-14 - Skip explicit audio extraction for faster-whisper
**Learning:** `faster-whisper`'s internal FFmpeg natively accepts video files as input for transcription, providing automatic audio extraction without explicit, external steps. Relying on an explicit `ffmpeg` extraction to an intermediate WAV file introduces significant disk I/O and processing overhead. Additionally, using `info.duration` directly from `faster-whisper`'s transcription result is more robust and efficient than extracting duration manually using the standard `wave` module, especially since `wave.open` fails on raw video files.
**Action:** Always verify if a library's internal dependencies (e.g., FFmpeg) can handle the full scope of input formats directly before writing custom preprocessing logic. Skip intermediary file generation where an in-memory or integrated library solution exists to eliminate unnecessary disk I/O.
